# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Image Viewing

This configuration includes plugins for viewing images directly in Neovim:

- **image.nvim** - View images within Neovim
- **clipboard-image.nvim** - Paste images from clipboard

See [IMAGE_VIEWING.md](IMAGE_VIEWING.md) for detailed usage instructions.

### Keybindings

- `<leader>io` - Toggle image display
- `<leader>ir` - Render image
- `<leader>ic` - Clear images
- `<leader>ip` - Paste clipboard image
